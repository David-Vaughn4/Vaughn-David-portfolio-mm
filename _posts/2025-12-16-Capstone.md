# Capstone Project

## Summary
I am continuing to work on the walking table project I worked on last year with Evan Park. We originally chose this because it looked like an interesting project which would include hands on learning regarding mechanical and electrical engineering, emphasizing building skills in CAD and iteration. Hopefully, we will create tables which walk on rotating legs while maintaining an even tabletop. The original inspiration for this project was [The Carpentopod](https://www.decarpentier.nl/carpentopod).
